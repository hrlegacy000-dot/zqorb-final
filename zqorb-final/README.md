# ZQORB — Final Static Website

A dependency-free, responsive ZQORB site. It can be deployed directly to Vercel or any static host.

## Local preview
Open `index.html` directly, or run a local server:

```bash
npx serve .
```

## Vercel
Import this folder/repository into Vercel. No build command is required for a plain static site.

## Before launch
Replace `hello@zqorb.com` in `index.html` with the real ZQORB contact email if needed.
